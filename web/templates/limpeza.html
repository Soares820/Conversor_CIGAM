Orientação para preparar a base CIGAM antes da entrada em produção: o que o conversor já valida sozinho e o checklist do que conferir manualmente antes da carga.

Validações que o conversor já faz

Acontecem automaticamente na etapa de conversão — isso aqui é só para explicar o que cada aviso/erro significa.

{{ icon("alert-triangle") }}

Tamanho de campo

Cada coluna do gabarito CIGAM tem um limite (ex.: "20 caracteres" na linha R2). Se o valor do cliente ultrapassa esse limite, gera um aviso — ou é truncado automaticamente se a opção "Truncar" estiver marcada na tela de mapeamento.

{{ icon("alert-circle") }}

PK duplicada

As colunas escolhidas como chave (ex.: grupo + subgrupo + material) não podem se repetir entre as linhas enviadas. Se duas linhas tiverem a mesma combinação, a segunda é marcada como erro.

{{ icon("alert-circle") }}

Campo obrigatório vazio

Colunas marcadas como obrigatórias precisam vir preenchidas pelo cliente ou ter um default no gabarito. Sem os dois, a linha é marcada como erro e não deve ser carregada no banco.
